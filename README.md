# esphome-projects

Configurazioni ESPHome per progetti di domotica e making.

Ogni directory contiene un progetto autonomo con il proprio file YAML e un `secrets.example.yaml` da usare come base per il proprio `secrets.yaml` (non committato).

## Progetti

| Progetto | Descrizione | Articolo |
|---|---|---|
| Sveglia | Sveglia da comodino | [link](https://cecchelab.dev/blog/2026-04-sveglia-01) |

## Utilizzo

1. Clona il repo
2. Entra nella directory del progetto
3. Copia `secrets.example.yaml` in `secrets.yaml` e compila con i tuoi dati
4. Flasha con `esphome run <file>.yaml`

## Note

- Tutti i progetti usano `esp-idf` come framework
- Il file `secrets.yaml` non è mai committato
- Ogni progetto è indipendente dagli altri# esphome-projects
